Project Title: Retail Inventory & Vendor Performance Analysis

Industry: Retail & Wholesale

Tools Used: Python, SQL, Power BI

Libraries: Pandas, NumPy, Matplotlib, Seaborn, SciPy

Database: SQLite
Project description:-
This project focuses on analyzing retail and wholesale business performance to understand sales, purchases, vendor contributions, product profitability and inventory management.

The main objective is to identify business problems that affect profitability, increase purchasing efficiency and improve inventory management.

Using SQL, Python and Power BI, I performed data extraction, cleaning, exploratory data analysis, statistical analysis and dashboard development.

The analysis helps businesses understand which vendors contribute the most, which products offer better profit opportunities, how bulk purchasing affects unit costs and where unsold inventory may create financial risks.
